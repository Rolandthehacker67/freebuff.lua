    Help & FAQ

    Where does the script get its login from?

    From this backend. The script asks for a one-time code, you confirm it here, and the script receives a session token hash-stored on the server. The token is revocable and expires.

    My code says “expired”

    Codes live for 5 minutes and work once. Tap Link device in the script again for a fresh code.

    Why does something say “Unavailable”?

    Account, usage and models come from Freebuff endpoints that must be configured and confirmed in the backend’s config.js. While a route is empty or unreachable, the UI shows “Unavailable” instead of inventing numbers.

    Is my Freebuff password stored anywhere?

    No. It is never typed into Roblox and never stored in this system.

    How do I unlink a device?

    Account page → Linked devices → Revoke. The script falls back to the login screen on its next launch.

    Keyboard shortcuts

    Code field: paste works, uppercase is automatic. Everything is reachable with Tab/Enter; focus styles are visible.
